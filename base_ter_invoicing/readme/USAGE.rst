To use this module:

#. Navigate to **Census > Parcels** and open a parcel form.
#. In the **Stakeholders** tab, set the **Overhead %** for each partner link.
   The sum of all overhead percentages must equal 100%.
#. The **Overhead area** is automatically computed as the official area
   multiplied by the overhead percentage.
#. For owners (profile = Owner), the **Ownership area** is also computed
   based on the ownership percentage.
#. To generate invoices, go to **Invoicing > Mass Invoicing** and select the
   *Areas* billing category. The module uses the overhead area as the invoiced
   quantity for each billable item.
#. On the parcel form, click the **Invoiced** stat button to see all related
   invoice lines.
