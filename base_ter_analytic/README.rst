Description
===========

This module extends **Territorial Use Units** (``ter.use_unit``) with an **analytic account**
(``account.analytic.account``). It depends on the **analytic** module and displays the analytic
account in all main views (form, list, kanban, search, pivot).

Use cases:

* Link territorial units to analytic accounts for cost/revenue tracking.
* Group and report by analytic account in list and pivot views.
* Filter and search territorial units by analytic account.

Installation
============

#. Install the **analytic** module (Odoo standard or OCA).
#. Install **base_ter** and **base_ter_analytic**.
