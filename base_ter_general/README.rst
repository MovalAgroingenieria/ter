============================
Area-based Massive Invoicing
============================

.. contents::
   :local:

Description
===========

This module extends the massive invoicing module (``base_invoicing``) to support area-based billing.

Features
========

* Allocate a percentage of overhead costs to each parcel stakeholder.
* Generate mass invoices by surface area, where the invoiced amount is computed by applying the overhead percentage to the parcel total area.
